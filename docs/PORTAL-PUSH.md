# What leaves the machine (portal push)

| Leaves desktop | Stays local |
| --- | --- |
| Phase / progress % | BOQ line drafts · measurements |
| Estimate **totals** (finalized) | Estimate line scratch |
| READY drawings · issued PDFs | Draft CAD/PDF |
| Issued invoices · certified RA scalars | Unissued money docs |
| Approval state · task status | AI chats · model weights |

Firm portal shows: **Updates · Progress · Drawings · Documents/numbers**.
Thin portal writes (approve / bid / visit) happen on the hub only.
