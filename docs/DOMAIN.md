# AStudio domain (architecture practice)

Reference IA from esti [NAVIGATION.md](https://github.com/HolagundiWorks/esti/blob/main/docs/esti/NAVIGATION.md)
— implement natively, do not embed the React SPA.

## Priority modules

| Area | Intent |
| --- | --- |
| Studio Intelligence | Office health · KPIs · attention (local calc + ESTI) |
| Projects / brief / R&O | Practice project record |
| Fees · proposals · invoices | India COA/GST money (paise) |
| Drawings · transmittals | Issue READY → publish artifact |
| Delivery | Snags · instructions · progress · BBS via engine |
| Estimation | Rate books + BOQ via C++ engine |
| Team / tasks / ASPRF | Local work; status meta to hub |
| Library | Spec / compliance / standards (local + optional hub) |

## Out of scope here

- Full PMC contractor ERP (that is **AQC**)  
- Browser staff workspace
